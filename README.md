# Сверка КВР (`sverka-kvr`)

Веб-приложение на **Streamlit** для автоматического заполнения столбца «Вывод» в чек-листах аудита карт выполненных работ (КВР): факт/простой, трудозатраты, материалы, транспорт.

## Цель и задачи проекта

- **Цель:** Автоматизировать ежемесячную проверку чек-листов аудита КВР и уйти от ручного построчного разбора таблиц в Excel.
- **Ключевые задачи:**
  - загружать книги Excel и автоматически нормализовать столбцы чек-листа;
  - рассчитывать статус по каждой строке правиловым парсером чисел и типовых формулировок;
  - передавать спорные строки с низкой уверенностью в LLM через OpenAI-совместимый API (опционально);
  - собирать сводную таблицу по цехам, строить диаграммы и выгружать итоговую книгу Excel.

## Результаты

- Сокращение времени первичной обработки чек-листа с нескольких часов ручной сверки до нескольких минут.
- Прозрачное разделение строк на однозначно проверенные правилами и требующие внимания специалиста.
- Готовая книга Excel с тремя листами («Результат», «Сводка», «Графики») и развёртывание сервиса в Docker на VPS с доменом и HTTPS (`https://sverka-kvr.ru`).

## Использованные технологии и библиотеки

- **Язык:** Python 3.10+
- **Анализ данных и экспорт:** `pandas`, `openpyxl`, `matplotlib`
- **Веб-интерфейс:** `streamlit`
- **ИИ и конфигурация:** `openai` (ProxyAPI), `python-dotenv`
- **Инфраструктура:** `Docker`, `Docker Compose`, Linux VPS

## Возможности

- загрузка Excel и выбор листа;
- заполнение вывода по правилам;
- правка итогового вывода в интерактивной таблице;
- сводка по цехам;
- графики аудита в интерфейсе и в Excel;
- выгрузка книги с листами «Результат», «Сводка», «Графики».

## Запуск

Нужен Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется адрес вида `http://localhost:8501`.

### Переменные окружения

Файл `.env` в репозиторий не входит. Скопируйте значения из `EnvExample`:

```env
PROXY_API_KEY=
PROXY_BASE_URL=https://api.proxyapi.ru/openai/v1
PROXY_MODEL=gpt-4o-mini
```

Без ключа приложение работает полностью: API нужен только если включить сверку спорных строк.

## Деплой на сервер (Docker + SSH)

Приложение слушает порт **8501**. Секреты живут только в `.env` на сервере, в образ они не попадают.

```bash
git clone https://github.com/gordanton/sverka-kvr.git
cd sverka-kvr
cp EnvExample .env
nano .env
docker compose up -d --build
```

Полезные команды:

```bash
docker compose logs -f        # логи
docker compose restart        # перезапуск
docker compose down           # остановить
```

Локально тот же compose: в папке проекта `docker compose up --build` и открыть `http://localhost:8501`.

## Структура проекта

```text
app.py                 # веб-интерфейс Streamlit
src/                   # парсер, правила, сводка, графики, клиент API
EnvExample             # шаблон переменных окружения
Dockerfile             # образ приложения
docker-compose.yml     # запуск контейнера
.streamlit/            # конфигурация сервера (0.0.0.0:8501)
requirements.txt       # зависимости Python
presentation/          # генератор презентации по результатам сверки
```

Чек-листы с реальными производственными данными в репозиторий не кладутся: загружайте свой Excel через интерфейс.
